# Pelham Engagement Project — Reviewer Briefing

A civic transparency site for Pelham, NY. AI-generated meeting summaries, election coverage, current issues tracking, and an AI assistant trained on local civic data. Built by one person; intended to eventually be handed off to the Pelham Examiner for ongoing maintenance.

## How content updates work (post-refactor)
1. Edit the relevant `content/*.json` file
2. Run `npm run build`
3. Review the diff in `index.html`
4. Run `npm run test:local` (builds first, then runs 21 UI tests)
5. Commit both JSON change AND generated files
6. Push → Netlify deploys

**Never hand-edit `index.html` directly** — it's generated. `npm run build:check` exits 1 if the generated output differs from what's committed.
